## Prerequisites

- Full Xcode installed at `/Applications/Xcode.app` and selected with `xcode-select`. Command Line Tools alone are not enough.
- Ruby gems installed with `task bundle:install` (vendored to `vendor/bundle`).
- `.env` populated (see `.env.example`). `task` loads it automatically. Running `fastlane` directly bypasses it, so source it first (`set -a; . ./.env; set +a`).

## Known Issues

### "Unable to locate Xcode" / "tool 'xcodebuild' requires Xcode"

`xcode-select -p` points at `/Library/Developer/CommandLineTools`. Setting `DEVELOPER_DIR` for the fastlane process is NOT enough: `tauri ios build` shells out to `xcodebuild` and ignores it. Fix system-wide (needs sudo):

```bash
sudo xcode-select -s /Applications/Xcode.app/Contents/Developer
```

### Linker error: `swiftCompatibility56` / `swiftCompatibilityConcurrency` not found

Symptom: `Undefined symbols for architecture arm64: __swift_FORCE_LOAD_$_swiftCompatibility56` and `ld: warning: search path '.../MetalToolchain-.../Metal.xctoolchain/usr/lib/swift/iphoneos' not found`.

Cause: the Tauri-generated `project.yml` sets `LIBRARY_SEARCH_PATHS` with `$(TOOLCHAIN_DIR)/usr/lib/swift/...`. On Xcode 26.x with the Metal toolchain component installed, `$(TOOLCHAIN_DIR)` resolves to `Metal.xctoolchain`, which does not contain the `libswiftCompatibility*.a` libraries. They live in `XcodeDefault.xctoolchain`.

Fix: `fix_tauri_project_yml` in `fastlane/Fastfile` rewrites `$(TOOLCHAIN_DIR)/usr/lib/` to `$(DEVELOPER_DIR)/Toolchains/XcodeDefault.xctoolchain/usr/lib/` and regenerates the project with `xcodegen`. It is idempotent and runs on every `beta`, `release`, and `build_only` lane.

Do NOT re-download the Metal toolchain (`xcodebuild -downloadComponent MetalToolchain`) to fix this. It was tried and changes nothing.

### Files modified by a build

A lane run rewrites `src-tauri/tauri.conf.json` (version, build number), `src-tauri/gen/apple/lunch_iOS/Info.plist`, `src-tauri/gen/apple/lunch.xcodeproj/project.pbxproj`, and `src-tauri/gen/apple/project.yml`. These are normal pre-build edits and are not part of the change being deployed.
